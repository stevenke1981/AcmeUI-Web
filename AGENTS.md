# AGENTS.md
## Mission
Maintain AcmeUI Web as a framework-neutral, semantic-first component and template platform.
## Workflow
1. Read `spec.md`, `plan.md`, and `todos.md`.
2. Keep React, Vue, Tailwind, and static HTML visually aligned.
3. Use semantic CSS variables; do not hardcode product colors in components.
4. Update Gallery examples with public component changes.
5. Run `pnpm test`, typecheck and builds before completion.
6. Destructive deletion and force-push require approval.
## Quality gates
WCAG AA baseline, keyboard-visible focus, 360/768/1280/1536 responsive checks, no token drift.
