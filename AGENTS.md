# AGENTS.md
## Mission
Maintain AcmeUI Web as a framework-neutral, semantic-first component and template platform.
## Workflow
1. Read `spec.md`, `plan.md`, and `todos.md`.
2. Read `skills/acmeui-web/SKILL.md` for AcmeUI Web implementation, review,
   scaffolding, token, template, release, or deployment tasks; load only the
   referenced resource needed for the current task.
3. Keep React, Vue, Tailwind, and static HTML visually aligned.
4. Use semantic CSS variables; do not hardcode product colors in components.
5. Update Gallery examples with public component changes.
6. Run `pnpm test`, typecheck and builds before completion.
7. Destructive deletion and force-push require approval.
## Quality gates
WCAG AA baseline, keyboard-visible focus, 360/768/1280/1536 responsive checks, no token drift.
