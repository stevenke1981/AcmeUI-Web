總覽

與 React、Vue 和 Tailwind 共用語意樣式。

使用方式

可選的 ES module 不會自動變更頁面；初始化函式傳回 cleanup。tab 與 panel 的 id 必須在整份文件唯一且不含空白；歧義關聯會在變更標記前被拒絕，修正後可重試。

鍵盤

方向鍵循環切換；Tab 前往目前內容。

對話框內容

此範例使用原生 dialog。沒有 JavaScript 或不支援 showModal 的瀏覽器仍可閱讀這段說明。

原生 Modal

瀏覽器處理背景 inert 與 Tab／Shift+Tab；Escape 或關閉按鈕會還原開啟者焦點。
