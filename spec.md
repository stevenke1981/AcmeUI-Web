# AcmeUI Web — Specification
## Goal
A source-available multi-framework UI system inspired by shadcn/ui, MUI, Ant Design, Mantine, Chakra UI, Element Plus, Semi Design, Arco Design and AcmeUI Native's layered architecture.
## Deliverables
- Shared semantic tokens and framework-neutral CSS
- React and Vue 3 component packages
- Tailwind CSS v4 adapter and plain HTML package
- CLI project generator and Gallery
- 48 deployable static templates
- Documentation, CI, Docker, tests and examples
## Acceptance
React/Vue component families match; every registry item has a preview; CLI generates React/Vue/static projects; validation passes.
