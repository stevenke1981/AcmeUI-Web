# Agent Prompt Examples

## Create a site

> Use the AcmeUI Web skill. List suitable templates, choose the closest template for an AI developer tool, generate a React site, convert the main sections into native `@acmeui/react` components, then run build and responsive checks.

## Add a component

> Use the AcmeUI Web skill. Add a reusable Combobox component. Keep React and Vue APIs equivalent, put visual rules in shared styles, add a static example and Gallery demo, and run all quality gates.

## Add a template

> Use the AcmeUI Web skill. Add a Traditional Chinese manufacturing company template named `industrial-manufacturer`. Support React, Vue, and static CLI generation. Update the registry, preview, catalog, and tests.

## Review the repository

> Use the AcmeUI Web skill. Audit token usage, React/Vue export parity, template registry integrity, CLI generation, accessibility, and responsive behavior. Fix high-confidence issues and record every command run.

## Theme work

> Use the AcmeUI Web skill. Add a high-contrast theme without breaking light/dark themes. Use semantic foreground/background pairs, update Tailwind mappings, demonstrate it in Gallery, and validate WCAG-oriented focus/contrast behavior.

## Repair generated output

> Use the AcmeUI Web skill. Reproduce why the Vue output for `analytics-dashboard` fails to build, fix the CLI generator rather than patching one generated project, and run the full template/framework matrix.
