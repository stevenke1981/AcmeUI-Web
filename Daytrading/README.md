# 台股當沖情報站

一個以當沖成本試算為核心、搭配 TWSE／TPEx 官方最近收盤與公告資料的台股訊息站。使用者可先掌握市場概況、熱門成交股、官方消息與個股當沖資格，再直接完成損益試算。

買進價與賣出價會雙向自動帶入，並把手續費與證交稅納入計算，預設確保試算淨報酬率至少 `1%`。頁面另附 Suno 原創歌曲〈一飛衝天〉，可直接播放或下載。

頁面下方另有「當沖基本常識與必要條件」，整理一般個人常見的帳戶滿 3 個月／近 1 年成交 10 筆、券商核准、當沖標的、同日同量沖銷、資金／券源，以及新手常見成本與風險；實際資格仍以券商和官方最新公告為準。

市場資料屬官方最近可用收盤／公告資訊，不是逐筆即時行情。網站已加入 Google AdSense Auto ads 發布者腳本（`ca-pub-7808800294872316`）；是否顯示仍取決於 AdSense 帳戶審核與 Auto ads 設定。

## 使用情境

- 盤前評估：輸入預計進出場價格，確認成本後是否仍有足夠利潤。
- 盤中試算：快速比較不同出場價的淨損益。
- 盤後核對：以券商實際費率、折扣與最低手續費調整試算。
- 市場速覽：查看上市／上櫃最近收盤摘要、成交熱門股與資料日期。
- 個股查詢：以代碼或名稱查詢 OHLC、成交量值及官方當沖標的狀態。
- 官方消息：閱讀證交所最新新聞並回到原始官方頁面。

## 預設假設

- 市場：台灣上市／上櫃現股當沖。
- 證券交易稅：賣出成交金額的 `0.15%`，適用期間依現行法規至 2027-12-31。
- 券商手續費率：買賣各 `0.1425%`。
- 電子下單折扣：`2.8 折`，可自行調整。
- 每筆最低手續費：`NT$20`，可關閉或調整。
- 金額顯示：新台幣整數；試算採明確且一致的四捨五入規則。

券商可自行訂定實際手續費率、折讓與每筆最低費用，因此所有費率都必須可修改。此工具僅供試算，不構成投資、稅務或交易建議；最終金額以券商成交回報與對帳單為準。
