# 實作計畫

## 模式

AcmeUI Web `Use components / static application` + Cloudflare Pages Functions。這是獨立市場資訊與試算頁，不新增公共元件、不修改模板 registry。

## 工作順序

1. 建立語意 HTML：頁首、輸入表單、結果摘要、成本明細、進階設定、來源與免責聲明。
2. 建立語意 Token 與響應式 CSS：桌面雙欄、手機單欄、狀態樣式、可見焦點、reduced-motion。
3. 實作純函式計算核心、輸入驗證、貨幣格式化與二分搜尋損益兩平價。
4. 連接即時計算、方向切換、股數快捷鍵、進階設定、錯誤訊息與重設。
5. 新增 Node 測試，涵蓋預設案例、虧損、最低手續費關閉、無效輸入、先賣後買文字脈絡與損益兩平價。
6. 執行專屬測試與 monorepo 品質門檻。
7. 以瀏覽器檢查 360、768、1280、1536 px、鍵盤流程、淺／深色或高對比適應、結果狀態與無效輸入。
8. 更新 `todos.md`、`test.md` 與 `final.md`，記錄實際證據與剩餘限制。
9. 加入雙向自動對價與至少 1% 的目標淨報酬率，並以純函式測試一分價邊界。
10. 產製 Suno 原創歌曲〈一飛衝天〉，加入不自動播放的頁內播放器、MP3 下載與歌詞文件。
11. 將網站與歌曲資產部署至 Cloudflare Pages，實測正式環境。
12. 補上當沖基本常識與必要條件教育區塊，附官方查核入口並維持免責聲明。
13. 建立 Pages Function 官方資料 Adapter，正規化 TWSE／TPEx 市場、熱門股、新聞與當沖標的。
14. 將首頁演進成「台股當沖情報站」，加入市場摘要、熱門股、官方消息與個股查詢。
15. 實作同源資料載入、部分失敗、重試與收盤價帶入計算器。
16. 補齊 Function／前端測試、四寬度真人驗收、Baseline、Git 與 Cloudflare production 驗收。

## 實作原則

- 保持零相依與可直接開啟。
- 計算邏輯和 DOM 邏輯分離。
- 不把產品色彩寫死在元件選擇器中；所有顏色經語意變數使用。
- 不修改 `E:\AcmeUI-Web` 其他模板、套件與公共 API。
- 不加入與試算無關的圖表、行情假資料或裝飾性儀表板。
- 市場區只能顯示官方最近可用資料，必須附日期與非即時警語。
- 上游失敗不得影響既有 `calculator.js`。
