# 台股訊息站與當沖損益計算機 — 產品規格

## 1. Outcome

製作一個免登入的繁體中文台股訊息站，讓使用者在同一頁查看官方最新收盤／公告資訊、搜尋個股與當沖資格，再於 10 秒內完成一次當沖試算。

當沖計算機仍是首頁主功能。市場資訊只使用 TWSE／TPEx 官方資料，清楚顯示資料日期且不宣稱即時行情；產品不預測漲跌、不提供買賣訊號。

## 2. 目標使用者

- 第一次接觸台股當沖、尚不熟悉交易成本的人。
- 想快速掌握上市、上櫃市場最近收盤概況與官方消息的人。
- 想查詢股票收盤資訊與是否列入當沖標的，再進行成本試算的人。
- 想在下單前快速確認「價差扣掉成本還剩多少」的交易者。
- 想以自己的券商折扣與最低手續費核對損益的人。

## 3. 核心流程

1. 使用者開站先看到當沖計算主區，以及具資料日期與非即時標示的市場摘要。
2. 使用者可瀏覽上市／上櫃市場概況、成交熱門股與證交所官方消息。
3. 使用者以股票代碼或名稱搜尋，查看最近收盤 OHLC、成交量值與官方當沖標的狀態。
4. 使用者可把搜尋結果的收盤價帶入買價，接著由計算機自動反推至少 `1%` 的賣價。
5. 使用者也可直接選擇 `先買後賣` 或 `先賣後買`，輸入任一價格與股數完成試算。
6. 畫面即時更新淨損益、報酬率、總成本與損益兩平賣價。
7. 市場 API 失敗時，顯示可理解的部分資料／錯誤狀態與官方連結，計算機維持可用。
8. 使用者可閱讀當沖常識、調整費率、播放〈一飛衝天〉並查看官方來源。

## 4. 資訊架構

### 頁首

- 產品名：`台股當沖情報站`
- 副標：`先掌握市場，再把成本算清楚。`
- 精簡風險提示與「試算，不是投資建議」標籤。
- 提供跳至 `市場資訊`、`個股查詢`、`當沖試算`、`當沖常識` 的頁內導覽。

### 市場資訊

- 上市大盤：資料日期、加權指數、漲跌點與成交金額。
- 上櫃市場：資料日期、櫃買指數、漲跌點、成交金額與漲跌家數。
- 成交熱門股：上市／上櫃依官方最近成交金額排序，顯示代號、名稱、收盤、漲跌與成交值。
- 官方消息：列出最近的 TWSE 新聞標題、日期與原始連結。
- 顯示載入中、成功、部分成功、錯誤與重試狀態；任何狀態皆不可使用假行情。

### 個股查詢

- 接受股票代碼或名稱。
- 顯示市場、資料日期、開盤、最高、最低、收盤、漲跌、成交量與成交值。
- 顯示是否列於官方現股當沖標的，以及暫停先賣後買註記。
- `帶入當沖計算` 只更新買進價並觸發既有自動對價，不覆寫股數與費率。

### 輸入卡

- 交易方向：分段控制 `先買後賣` / `先賣後買`。
- 買進價：正數，最多 2 位小數。
- 賣出價：正數，最多 2 位小數。
- 股數：正整數；提供 `100 / 500 / 1,000 / 2,000` 快捷選項。
- 每個欄位都有單位、短說明與行內錯誤訊息。
- 無效輸入時不以 `NaN` 或誤導性的零元結果取代，結果區顯示「請先完成有效輸入」。

### 結果卡

- 主要結果：`預估淨獲利` 或 `預估淨損失`。
- 狀態文字與顏色必須雙重表達，不可只靠紅綠。
- 次要指標：
  - 投入金額
  - 毛價差
  - 交易總成本
  - 淨報酬率
  - 損益兩平賣價
- 一句人話摘要，例如：`每股價差 NT$1.00，扣除約 NT$232 成本後，預估淨賺 NT$768。`

### 成本明細

- 買進成交金額
- 買進手續費
- 賣出成交金額
- 賣出手續費
- 證券交易稅
- 總成本
- 淨損益

### 進階設定

預設收合，展開後包含：

- 券商手續費率（%），預設 `0.1425`。
- 手續費折扣（折），預設 `2.8`，允許 `1–10`。
- 每筆最低手續費（NT$），預設 `20`。
- 套用最低手續費開關，預設開啟。
- 當沖證交稅率（%），預設 `0.15`。
- 目標淨報酬率（%），預設與最低值皆為 `1`。
- 顯示「各券商規則不同」提示。

### 頁尾

- 官方參考連結。
- 資料更新標記：`法規預設值核對：2026-07-23`。
- 免責聲明。
- TWSE OpenAPI、TPEx OpenAPI 與資料使用說明。

### 當沖基本常識

- 清楚說明現股當沖是同一帳戶、同一營業日、同種類同數量的反向沖銷。
- 以「下單前的必要條件」清單說明一般個人常見的帳戶滿 3 個月／近 1 年成交 10 筆、風險文件、當沖標的、同日同量沖銷，以及資金／券源／額度確認。
- 以「新手一定要知道」提醒雙邊手續費、賣出證交稅、滑價、漲跌停、未成交與未沖銷風險。
- 提供證交所當沖專區、每日標的、風險預告書與財政部稅法官方連結。
- 明確標示內容是一般性教育資訊，不能取代券商審核、個別契約或即時公告。

## 5. 計算規格

所有百分比輸入先除以 100；折數輸入先除以 10。

```text
買進成交金額 = 買進價 × 股數
賣出成交金額 = 賣出價 × 股數
買進手續費原值 = 買進成交金額 × 手續費率 × 折扣倍率
賣出手續費原值 = 賣出成交金額 × 手續費率 × 折扣倍率
單邊手續費 = 四捨五入(max(手續費原值, 最低手續費))
證券交易稅 = 四捨五入(賣出成交金額 × 證交稅率)
毛價差 = 賣出成交金額 − 買進成交金額
交易總成本 = 買進手續費 + 賣出手續費 + 證券交易稅
淨損益 = 毛價差 − 交易總成本
淨報酬率 = 淨損益 ÷ 買進成交金額 × 100%
```

關閉最低手續費時，`max()` 只取手續費原值。顯示金額採 `Intl.NumberFormat("zh-TW", { style: "currency", currency: "TWD", maximumFractionDigits: 0 })`。

損益兩平賣價不可使用忽略最低費用與取整的簡化公式；應以二分搜尋找到在目前設定下 `淨損益 >= 0` 的最低賣價，搜尋精度至少到 `NT$0.01`。若輸入不完整則顯示 `—`。

自動對價同樣納入買賣手續費、最低手續費與證交稅；輸入買價時找出可使淨報酬率達標的最低一分價賣價，輸入賣價時找出仍可達標的最高一分價買價。

## 6. 預設案例與可驗證結果

預設輸入：

```text
買進價 100
賣出價 101.24（由 1% 目標自動帶入）
股數 1,000
手續費率 0.1425%
折扣 2.8 折
最低手續費 NT$20（啟用）
當沖證交稅率 0.15%
```

預期：

```text
買進成交金額 NT$100,000
賣出成交金額 NT$101,240
買進手續費 NT$40
賣出手續費 NT$40
證券交易稅 NT$152
毛價差 NT$1,240
交易總成本 NT$232
淨損益 NT$1,008
淨報酬率 1.008%
```

## 7. 視覺方向

- 調性：冷靜、可信、金融工具感，但避免專業交易終端的資訊壓迫。
- 版面：桌面雙欄，左側輸入、右側結果；成本明細與說明置於下方。手機改為單欄，結果緊接輸入。
- 色彩：全程使用語意變數；中性深藍灰作主色，正向用青綠、負向用磚紅、提醒用琥珀。
- 不把正向結果做成炫耀式慶祝動畫；數字變化使用極短淡入，且遵守 `prefers-reduced-motion`。
- 數字使用等寬數字特性 `font-variant-numeric: tabular-nums`。
- 卡片層級靠邊框、背景與留白建立，不堆疊濃重陰影。

建議語意變數：

```css
--surface-canvas
--surface-card
--surface-subtle
--text-primary
--text-secondary
--border-default
--accent-primary
--status-positive
--status-negative
--status-warning
--focus-ring
```

## 8. 響應式與可存取性

- 驗證寬度：360、768、1280、1536 px。
- 所有控制項具有可見 `label`，錯誤訊息以 `aria-describedby` 關聯。
- 結果摘要使用 `aria-live="polite"`，但避免每個按鍵都朗讀整張明細。
- 分段控制、快捷股數、進階設定與重設按鈕皆可用鍵盤操作。
- 焦點輪廓清楚可見，對比符合 WCAG AA。
- 觸控目標至少 44 × 44 px。
- 支援 `prefers-reduced-motion` 與 Windows 高對比／forced-colors 基本可用性。

## 9. 技術與檔案邊界

交付為 `Daytrading` 目錄內的零前端相依頁面，市場資料由 Cloudflare Pages Functions 同源代理：

```text
Daytrading/
  index.html
  styles.css
  calculator.js
  calculator.test.mjs
  market-info.js
  market-info.test.mjs
  functions/
    api/
      market.js
      stock.js
    _shared/
      market-data.mjs
  _routes.json
  audio/
    yi-fei-chong-tian.mp3
    一飛衝天-歌詞.md
  README.md
  spec.md
  plan.md
  todos.md
  test.md
  final.md
```

- 不修改 AcmeUI 公開元件 API，不需同步 React／Vue 套件或 Gallery。
- 使用 AcmeUI 的 `acme-*` 類別命名精神與語意化 CSS 變數。
- 核心計算函式需可由 Node 測試匯入；DOM 初始化必須在無 `document` 的 Node 環境安全跳過。
- 不使用遠端字型、非官方行情 API、一般追蹤碼或瀏覽器儲存；保留使用者指定的 Google AdSense Auto ads loader。
- 市場資料只從 TWSE／TPEx 官方 OpenAPI 取得，經同源 Pages Function 正規化與快取。
- `index.html` 以檔案直接開啟時，計算器仍須正常；市場區可顯示「正式站提供資料」的降級狀態。

## 10. 非目標

- 不串接券商帳戶、下單、逐筆即時報價或持倉。
- 不處理融資、融券借券費、ETF／權證／期貨等不同稅制。
- 不保存交易紀錄，不建立登入或雲端同步。
- 不以計算結果推導停損、停利或交易建議。
- 不建立新聞聚合爬蟲、社群情緒、AI 選股或推薦排名。
